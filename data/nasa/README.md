# NASA 18650 Battery Dataset

**Source:** NASA Ames Prognostics Data Repository

**URL:** https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/ames-prognostics-data-repository/

**Direct download:** https://ti.arc.nasa.gov/tech/dash/groups/pcoe/prognostic-data-repository/#battery

**Citation:**
B. Saha and K. Goebel, "Battery Data Set," NASA Ames Prognostics Data Repository, 2007.

**Expected contents:** 6 folders (BatteryAgingARC_*) containing `.mat` files with discharge cycle data for 37 LCO 18650 cells.
